# GDI 论文故事：定位有效干预层，增强迁移攻击

更新日期：2026-11-05。方法名为 GDI（Geometry-Guided Depth Intervention）。本文档记录论文主张、故事和证据安排；论文自然段按 `AGENTS.md` 的对话工作流逐段交付。

## 1. 研究目标与两项创新

研究目标是通过选择模型内部有效的输入干预层，获得更强的对抗攻击迁移效果。论文围绕以下两项创新展开。

1. **有效干预层的发现。** 模型的一次前向传播中，一些层可能承担较重要的信息汇总作用；在攻击迭代的前向过程中干扰这些层的输入，可以获得较好的迁移攻击效果。论证重点落在这些层的迁移攻击价值。
2. **有效干预层的定位。** 提出一种模型无关、样本相关的计算方式，利用一次干净前向中的特征几何，为每张图像定位对迁移攻击更有效的层。GDI 使用方向方差比与正收缩比例的乘积进行定位，并在所选层输入处均匀随机清零局部 token。

“模型无关”指不同源模型采用统一的计算原则，按其原生特征、全局参考和 block 边界执行。“样本相关”指每张图像根据自身干净特征确定干预层。干预边界在攻击期间固定，token 位置按 step/group 重采样。

## 2. 故事主线

**干预深度影响迁移效果 → 发现有效干预层及其表示特征 → 提出逐样本定位方式 → 在所选层输入处随机干扰 → 以迁移 ASR 检验完整方法。**

从迁移攻击中的一个实际选择切入：模型内部的哪一层适合施加干扰？真实样本的跨层局部—全局关联变化，以及 block 前后的局部分布变化，帮助观察可能承担信息汇总作用的层。随后用相应干预的 ASR 比较呈现这些层的攻击价值，将观察推进到自动定位问题。

GDI 将局部特征沿全局方向的差异和 block 前后的正收缩结合起来，给出统一的逐样本选层分数。在最高分 block 的输入处实施随机 token 清零，以此计算攻击梯度并优化可迁移扰动。方法的定位能力通过匹配设置的选层 ASR 对照检验，完整效果通过四源 FPR13 主结果呈现。

## 4. 方法事实

每张干净图像在攻击前做一次无干扰的前向，保存所有候选 block 的局部输入和输出。将局部向量及全局参考从 float32 转为 float64，分别做 L2 归一化。记输入、输出局部 token 围绕各自中心的平均平方距离为输入、输出分散度。

输出沿全局单位方向的投影总体方差，除以输出分散度与原生特征维数的比值，得到方向方差比。再乘正收缩比例 `max(0, 1 - 输出分散度 / 输入分散度)`，选择分数最高的 block；并列按原生前向顺序取最早者。干预发生在该 block 的输入处。

选层完成后，在选定边界全部局部位置上均匀、无放回抽样，清零所选 token 全部通道，保留 prefix、token 数量和原生网格。同批图像可选择不同边界，每张图、每个视图均在自身选定的一个边界干预。

默认 seed 42、10 steps、10 groups × 2 views、epsilon=16/255。每图有 100 次原始 mask 抽样。完整统计、架构参考、取整和执行细节见 [方法契约](gdi_method_contract.md)。

## 7. 基础增强与实现设置

i.i.d. RGB 高斯采样经真实初始投影和逐样本 RMS 匹配形成随机特征增强。phase 空间配对、视图梯度平均、动量和投影更新组成共同攻击设置。主文在 §3.4 简洁串联，构造、参数与架构细节集中放补充材料及 [方法契约](gdi_method_contract.md)。

源模型为 ViT-B/16、CaiT-S24、PiT-T、DeiT-B distilled；总 drop 比例依次为 20/196、30/196、30/196、20/196。PiT 按选定原生网格记录实际数量。ASR 使用全部对抗样本的 `1 - adversarial accuracy`，strict 排除完全相同源目标，四源等权汇总。
